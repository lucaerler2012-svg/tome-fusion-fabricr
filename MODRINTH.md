# Mod-Name
Tome Fusion (Slug: tome-fusion)

# Kurzbeschreibung (max. ~80 Zeichen)
Addiere Buch-Level im Amboss - mit einer festen Obergrenze pro Verzauberung.

# Modrinth-Seitentext
## Tome Fusion

Im Vanilla-Amboss ergeben zwei Schärfe-II-Bücher nur Schärfe III. **Mit Tome Fusion werden die Level einfach addiert.**

### Beispiele
- Schärfe II + Schärfe II = **Schärfe IV**
- Schärfe V + Schärfe III = **Schärfe VIII**
- Schärfe VIII + Schärfe V = Schärfe XIII -> begrenzt auf **Schärfe X**

### Obergrenze
Das Ergebnis ist nie höher als das **Doppelte des Vanilla-Maximums** der Verzauberung
(Schärfe 5 -> max. 10, Federfall 4 -> max. 8).

### Kreativmodus
Eigener Tab "Tome Fusion" mit allen verzauberten Büchern, jede Verzauberung der Reihe nach von Level 1 bis zur Obergrenze (z. B. Schärfe 1 bis 10).

### Details
- Gilt für verzauberte Bücher im Amboss (Buch + Buch) und für Bücher auf Items (z. B. Schwert + Schärfe-Buch)
- Verschiedene Verzauberungen auf beiden Büchern werden übernommen
- Für den Singleplayer gedacht
- Benötigt Fabric API
